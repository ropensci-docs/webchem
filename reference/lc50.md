# Acute toxicity data from U.S. EPA ECOTOX

This dataset comprises acute ecotoxicity data of 124 insecticides. The
data is publicly available and can be retrieved from the EPA ECOTOX
database (<https://cfpub.epa.gov/ecotox/>) It comprises acute toxicity
data (D. magna, 48h, Laboratory, 48h) and has been preprocessed (remove
non-insecticides, aggregate multiple value, keep only numeric data etc).

## Usage

``` r
lc50
```

## Format

A data frame with 124 rows and 2 variables:

- cas:

  CAS registry number

- value:

  LC50value

## Source

<https://cfpub.epa.gov/ecotox/>
