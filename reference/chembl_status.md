# Retrieve ChEMBL webservice status

Retrieve status information about the ChEMBL webservice: database
version, release date, status, and count data for various entities.

## Usage

``` r
chembl_status(verbose = getOption("verbose"), ...)
```

## Arguments

- verbose:

  logical; should verbose messages be printed to the console?

- ...:

  additional arguments, only used for internal testing.
